# Hyderabad Patient Flow — one page site

A single, self-contained page for Hyderabad Patient Flow: three small things for
diagnostic labs and mid-size hospitals in Hyderabad so no patient enquiry goes cold.

## Files

- `index.html` — the whole page (HTML, CSS and a little JavaScript in one file).
- `images/` — `logo.png`, `speaking.jpg`, `working.jpg`, `profile.jpg`.

No build step. It is a static site.

## Before you publish

- In `index.html`, find `EMAIL_GOES_HERE` and replace it with the real email address,
  then delete the comment line above it.

## Deploy

Import this repository in Vercel and deploy. No settings need changing.
